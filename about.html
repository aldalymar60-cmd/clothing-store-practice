О проекте

Цели, решения и границы учебного прототипа.

Название и цель

Разработка интернет-магазина одежды. Цель — создать статический учебный каталог и информационный сайт проекта, затем реализовать собственный локальный HTTP-сервер для выдачи его файлов.

Актуальность и аудитория

Посетителю магазина важно быстро находить описание одежды, размер и цену. Прототип ориентирован на пользователей, которые знакомятся с ассортиментом с компьютера или телефона. Учебная ценность проекта — связь HTML/CSS, браузерного JavaScript, Git и сетевого программирования.

Задачи

  • Спроектировать страницы и навигацию.
  • Создать каталог с демонстрационными товарами.
  • Реализовать поиск, выбор категории и сортировку цен.
  • Подготовить адаптивную вёрстку и локальные графические материалы.
  • Написать HTTP-сервер на sockets без готового веб-фреймворка.
  • Проверить нормальные запросы и ошибки, подготовить руководство.

Реализованные страницы

Главная, О проекте, Участники, Журнал, Ресурсы, Каталог, HTTP-сервер. Основные страницы читаются без JavaScript. Каталог содержит статические карточки; JavaScript добавляет фильтрацию. Все страницы и изображения доступны при открытии site/index.html напрямую.

Границы

Это учебный прототип, а не действующий магазин. Оплата, регистрация, реальные заказы, склад и база персональных данных не реализованы. Товары, размеры и цены — демонстрационные данные. Фото задаёт визуальную тему, не является фотографией каждой позиции.

Результат

Подготовлены исходные файлы сайта, Python-сервер, автоматические тесты.
